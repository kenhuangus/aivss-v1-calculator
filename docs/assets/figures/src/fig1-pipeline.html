AIVSS scoring pipeline: lookup tables only

1. Score CVSS v4.0
Official FIRST algorithm, unchanged. Output: CVSS-BTE and its FIRST band (Low, Medium, High, Critical).
2. Assign agentic categories
LC, CP, AP, SR, ES as labels only. Use X when evidence is missing. SR must agree with AT.
3. Effect Class by ordered ladder
Test A2, then A1, then AX, then A0; the first match wins. Provisional when any of LC, CP, AP or SR is X.
4. Lookup Table AIVSS (Table 6)
A0 or AX: AIVSS equals CVSS-BTE. A1 or A2: the higher of the cell value and CVSS-BTE.
5. Publish
CVSS-BTE · Effect Class · U · AIVSS · provisional flag
Lookup Table U
Table 5. Effect Class, SR and ES give U from 0 to 10. Informative only: no decision uses U.
No arithmetic on ordinal labels: no sums, products, averages or CVSS-plus-uplift formulas.
